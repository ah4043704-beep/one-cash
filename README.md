# ون كاش — صفحة الدعوة الخاصة

صفحة تسجيل بيانات بلغة عربية (RTL) ومتوافقة تمامًا مع الهاتف لعلامة "ون كاش" (محفظة رقمية افتراضية).
يُدخل الزائر اسمه ورقم هاتفه اليمني ليحصل فورًا على رابط دعوة خاص به، مع عرض هدية ترحيبية بقيمة
500 ريال يمني. بعد الإرسال تنتقل الصفحة مباشرة إلى بطاقة نجاح تؤكد استلام البيانات.

## التقنيات المستخدمة

- **TanStack Start** (React 19 + TanStack Router) لواجهة وخادم موحّدين.
- **Vite 7** للبناء والتطوير.
- **Tailwind CSS 4** مع متغيرات CSS مخصّصة لهوية العلامة (التدرجات، الخطوط المتقاطعة، الحركات).
- **Netlify Database** (Postgres مُدارة) عبر **Drizzle ORM** لتخزين بيانات التسجيل ورابط الدعوة.
- **Zod** للتحقق من صحة البيانات في الخادم.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

يفتح الخادم المحلي على `http://localhost:3000`. لتشغيل محاكاة كاملة لمنصة Netlify (بما فيها قاعدة
البيانات) استخدم بدلاً من ذلك:

```bash
netlify dev --port 8889
```

## قاعدة البيانات

مخطط الجدول موجود في `db/schema.ts` (جدول `invites`: الاسم، الهاتف، رمز الدعوة، تاريخ الإنشاء).
أي تعديل على المخطط يتطلب توليد ملف ترحيل جديد:

```bash
npx drizzle-kit generate --name <وصف_التغيير>
```

يتم تطبيق ملفات الترحيل في `netlify/database/migrations/` تلقائيًا عند النشر على Netlify.
